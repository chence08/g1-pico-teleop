This repository contains the custom integration and commissioning tools developed for a Unitree G1 EDU 29-DOF robot with Inspire DFX hands and PICO XRoboToolkit input.

Third-party source, model assets, binaries and recordings are not vendored. Bootstrap fetches pinned upstream repositories; each retains its own license and notices. Consult `dependencies.lock.json` and those repositories before redistribution. No blanket license is asserted over third-party code or robot model assets.

The original custom integration has not yet been assigned a redistribution license by its owner. Repository access alone does not grant a general open-source license; choose an appropriate license before a public release.
